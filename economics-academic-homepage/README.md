# Zijun Wang academic homepage

The site has a clear academic structure: `Home`, `Research`, `Working Papers`, `Notes & Essays`, and `CV`. It intentionally does not include a Publications section yet.

## Maintain the Notes & Essays desk

For each new piece, copy `article-template.html`, rename it (for example, `notes/housing-and-liquidity.html`), and replace the title, date, summary, and body. Then add its title, date, two-sentence summary, and link to the archive in `notes.html`.

Recommended rhythm: a 500-800 word weekly note plus a 1,000-1,800 word monthly essay. The two formats keep the writing sustainable while creating a serious public archive over time.

## Publish for free

Create a GitHub account and a repository named `your-github-username.github.io`. Upload all files in this folder to the repository root, then enable **Settings → Pages → Deploy from a branch**. Your address will be `https://your-github-username.github.io`.

The site uses Google Fonts. If you prefer no external font request, remove the two font `<link>` tags in each HTML file; Georgia will be used instead.
